# Contributing

This repository contains a personal CV website. Unsolicited content changes may be declined.

All changes must:

1. Be proposed through a pull request.
2. Avoid committing secrets, credentials, private documents, or generated build output.
3. Pass the automated lint and production-build checks.
4. Receive approval from the repository owner before merge.

By contributing, you agree that your contribution may be used as part of this repository under its existing license terms.
